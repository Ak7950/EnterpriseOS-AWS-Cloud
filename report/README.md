# Project report (IEEE conference format)

`enterpriseos-aws-report.tex` is a single self-contained LaTeX file: figures are drawn with TikZ,
so no image files are needed. It follows the same IEEEtran layout as the Software Engineering report.

## Compile on Overleaf (recommended)

1. Overleaf → **New Project → Blank Project**.
2. Replace `main.tex` with the contents of `enterpriseos-aws-report.tex` (or upload the file and
   set it as the main document under **Menu → Main document**).
3. Compiler: **pdfLaTeX** (the default). Click **Recompile**.

## Before submitting

- Replace `[Course Code]` and `[Group No.]` in the title block.
- If the AWS stack has been deployed, update the abstract, Table II status column and
  Section IX ("Deployment Status") and add dated, redacted screenshots as a figure.
