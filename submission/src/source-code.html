1. Repository

https://github.com/Ak7950/EnterpriseOS-AWS-Cloud

Public GitHub repository (branch main). The README.md on the repository front page explains the project, architecture, AWS services, how to run it locally and how to deploy and clean up on AWS. A copy of the README is included with this submission. Every push runs GitHub Actions: tests, dependency audit, Lambda package smoke test, template and script linters and a secret scan, all passing.

2. Repository Structure

FolderContents
server/, public/EnterpriseOS application (Express API and web interface), plus event publishing and structured logging
aws/lambda/Lambda handlers: HTTP bridge, Parameter Store loader, SQS event worker
infrastructure/AWS SAM / CloudFormation template and reference IAM policies
scripts/aws/Pre-flight, secret setup, deploy and cleanup scripts
test/59 automated tests, including Lambda end-to-end and infrastructure checks
docs/Architecture, AWS service matrix, cost, security, deployment and cleanup guides, deployment evidence
.github/workflows/CI on every push; manual-only deploy and cleanup workflows

3. How to Run

Locally (Node.js 22 or later):

npm install
npm test        # runs the 59 automated tests
npm run dev     # opens on http://localhost:4000

Demo login (synthetic data): manager@demo.com / Demo@12345.

On AWS (AWS Academy sandbox, AWS CloudShell, us-east-1):

git clone https://github.com/Ak7950/EnterpriseOS-AWS-Cloud.git
cd EnterpriseOS-AWS-Cloud
npm ci
STAGE=dev bash scripts/aws/put-parameters.sh
CONFIRM_COST_CHECKLIST=yes STAGE=dev FRONT_DOOR=HttpApi \
  bash scripts/aws/deploy.sh
STAGE=dev DELETE_PARAMETERS=yes bash scripts/aws/cleanup.sh   # afterwards
