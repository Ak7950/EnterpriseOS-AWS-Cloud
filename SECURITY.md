# Security Policy

## Supported Versions

Security fixes are made on the current `main` branch.

## Reporting a Vulnerability

Do not open public issues for suspected vulnerabilities. Report them privately to the repository maintainers with a description, reproduction steps, impact, and suggested remediation if available. Do not include real credentials or sensitive production data.

The current implementation and known gaps are documented in [docs/security.md](docs/security.md).
